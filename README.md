# Feedback PWA - Premium Landing Page

A high-end, high-performance landing page for the **Feedback PWA**, an enterprise-grade standard for workshop management and certificate automation. Built with a sleek, modern aesthetic using the latest web technologies.

![Design Preview](public/landing-preview.png) *(Note: Add your actual preview image in public folder if available)*

## ✨ Key Features

- **Premium Aesthetics**: Dark mode by default with glassmorphism, grainy gradients, and smooth glowing accents.
- **Dynamic Animations**: Powered by `framer-motion` for scroll-triggered effects and interactive elements.
- **Interactive Dashboard Mockup**: A perspective-transformed dashboard preview in the hero section.
- **Enterprise Features Grid**: Showcase of core capabilities like automated certificates and data insights.
- **Product Showcase**: Detailed breakdown of the platform's utility.
- **Flexible Pricing**: Clean, informative pricing tiers for different scales.
- **Ultra-Responsive**: Fully optimized for mobile, tablet, and desktop screens.
- **Optimized Performance**: Leveraging Next.js 16's latest features and Tailwind CSS 4 for rapid loading and styling.

## 🚀 Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations**: [Framer Motion 12](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Fonts**: [Geist](https://vercel.com/font) & Plus Jakarta Sans

## 🛠️ Getting Started

### Prerequisites

Ensure you have **Node.js** and **pnpm** installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/feedback-pwa-landing-page.git
   cd feedback-pwa-landing-page
   ```

2. **Install dependencies:**
   ```bash
   pnpm install
   ```

3. **Run the development server:**
   ```bash
   pnpm dev
   ```

4. **Open the application:**
   Navigate to [http://localhost:3000](http://localhost:3000) in your browser.
